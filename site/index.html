Why Forecrew

A coding agent alone is fast, and it forgets.

The purpose lives in a conversation that gets summarized, "done" means the agent says so, and the same context that wrote the code reviews it. Forecrew puts the work in stages, on disk, with gates.

The purpose gets lost when the chat is summarized
It lives in .work/<ID>/00-purpose.md, with numbered criteria every stage cites.
The agent guesses where a choice is open
It writes [NEEDS CLARIFICATION] and asks you, one question at a time.
"Tests pass"
The tester reverts the fix and shows each test failing without it. The machine runs lint, build and tests first.
One context checks its own work
Four reviewers in parallel, each with a clean context and its own lens.
Decisions you never saw
Every ruling taken without you goes in a ledger, with its cost if wrong.
You babysit terminals
One page shows every task of every worktree. Whatever needs you raises its hand.

How a task runs

Every stage writes a file. Agents pass paths, not summaries.

Each answer starts with a fixed status line, so the orchestrator routes on facts, not prose. You confirm the lane; trivial changes skip ahead, the reviewers always run.

Where it runs

Not another app to live in. A layer in your repository.

Agents, commands, a hook and scripts under .claude/, plus a page in your browser. It runs wherever your agents already run, including inside apps that orchestrate many terminals: each one gets the same process, gates and evidence.

Get started

Five minutes from clone to first task.

Needs git, bash and Python 3. No tracker or docs tool required: describe what you want in plain words.

Get the kit and install it

Into any repository. Your existing AI configuration is kept unless you say otherwise.

git clone https://github.com/yantadeu/forecrew.git
./forecrew/install.sh /path/to/your/repo

Configure it by interview

A short set of questions: tracker, docs, stack, how your checks run.

cd /path/to/your/repo && claude
/flow-setup

Run your first task

With a ticket id, a link, or plain words. /task offers to open the dashboard.

/task add CSV export to the report page

Give your agents a crew, a process and a foreman.

Everything stays on your machine. Nothing in it needs an account.
