# Decisions

Rulings from task ledgers that the dev chose to keep after the task closes: the "why did we do
it this way?" of the repository. The retrospective proposes them, the dev approves, and the
task skill appends them. Search them with `python3 .claude/kit/scripts/learnings.py --search <words>`.

```
## <short-slug>
- **Tags**: comma-separated, from: security, qa, product, integration, workflow, data, tooling, process.
- **Decision**: what was decided, in one sentence.
- **Why**: the reason at the time.
- **Cost if wrong**: what breaks, and who notices.
- **From**: <task ID>, <date>. Superseded by: <slug>, when a later decision replaces it.
```
